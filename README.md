you need a [vencord](https://github.com/Vendicated/Vencord) **from source**. then:

1. run [`install.bat`](./install.bat) (drag your vencord folder onto it if it cant find it)
2. say yes to rebuild when it asks
3. fully quit discord and open it again
4. settings → vencord → plugins → filter **show all**

manual: copy a plugin folder into `Vencord/src/userplugins/`, `pnpm build`, dump `dist` into `%APPDATA%\Vencord\dist`. more detail [here](https://docs.vencord.dev/installing/custom-plugins/).
